## Como eu construo

Desenvolvo com **IA como ferramenta de trabalho** — uso Claude Code e outros assistentes para acelerar arquitetura, implementação e refatoração. Foi isso que me permitiu, vindo da área de operações, colocar cinco sistemas internos em produção em menos de um ano.

O que eu trago não é a digitação do código: é **saber qual problema vale ser resolvido**, modelar o processo, definir as regras de negócio, validar com quem usa e medir o resultado. A IA acelera a construção; o critério de o que construir e por quê continua sendo meu.
